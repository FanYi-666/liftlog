# LiftLog 健身与饮食记录

LiftLog 是一个手机优先的训练 + 饮食记录应用原型。目标是保留 Strong 类应用最有用的数据记录和趋势功能，不做动作教学。

## 当前 Web V1

### 首次使用与界面
- 真正的新用户首次打开会进入 3 步初始化：选择 kg/lb、训练目标和每周频率 → 按训练日选择胸/背/腿/后链/肩/手臂/核心等分化并自动生成周模板 → 设置饮食目标或选择暂不记录饮食。
- 2–6 天都有均衡默认分化：2 天全身 A/B、3 天上肢/下肢/全身、4 天上/下肢 A/B、5 天推/拉/腿+上/下肢、6 天推/拉/腿 A/B；主要肌群默认获得约 2 次周刺激。
- 每个训练日的重点都可自由修改；系统会提示一周覆盖不足或相邻训练日重复高负荷部位，但不会强行禁止自定义方案。
- 完成初始化后首页直接显示今天训练/休息建议；休息日会提示下一次训练日和模板，不再只展示空数据。
- kg/lb 只改变输入和显示，训练/身体历史底层仍统一保存为 kg，切换单位不会改写旧记录。
- 可关闭饮食记录；关闭后首页饮食行和底部饮食入口隐藏，之后可在设置重新开启。
- 界面采用“核心记录常驻、可选模块按需添加”的手机优先结构，减少训练页、饮食页和趋势页的纵向长度。
- 首页使用统一的饮食 / 训练 / 计划三行信息面板，去掉仪表盘式大卡、圆形进度环、整块渐变和装饰性英文标签，数据按同一基线规整排列。
- 设置中提供 9 个页面模块开关；隐藏模块不会删除数据，需要时可随时重新添加到界面。
- 极简默认下：首页只保留饮食/训练/计划；饮食页保留当天摘要、快速记餐与当天明细；训练页保留今日计划、动作选择、动作日期折线、组记录和保存。
- Smart Plan、恢复顾问、模板、实时对比、计算器、饮食趋势、身体记录、恢复分布、PR 时间线和逐日明细默认隐藏，可在设置里按需打开。
- 支持“跟随系统 / 深色 / 浅色”三档主题，主题选择保存在本浏览器；顶部提供浅/深色快捷切换按钮。
- iPhone PWA 的 theme-color 与状态栏样式会跟随当前浅/深色主题更新。

### 饮食与身体
- 每日饮食热量记录，与训练数据完全分开，不记录或混算训练消耗热量。
- 早餐 / 午餐 / 晚餐 / 加餐分类。
- 每条饮食可同时记录 kcal、蛋白质、碳水和脂肪；设置中可配置每日四项目标。
- 当天卡片同时显示热量与三大营养素进度。
- 常用食物会按历史使用频率自动排序，点击后直接填入最新记录值。
- 可把当天某一餐保存为“常用餐”，以后整餐一键加入并支持删除；也可一键复制前一天全部饮食。
- 最近 7 天每日摄入可点击切换日期；营养趋势支持 7 / 30 天平均热量与宏量营养统计和图表。
- 饮食记录支持编辑与删除，旧的纯 kcal 数据会自动兼容迁移。
- 可按日期记录体重与可选体脂；显示最新体重、7 天平均、30 天变化和最新体脂。
- 30 天“体重 × 热量”同轴趋势只用于观察阶段变化，不推断热量与体重变化之间的因果。

### 训练
- 自定义训练日期，可补录历史训练。
- 内置常见动作并支持自定义动作；动作可选择“负重”或“自重”记录方式。
- 训练页动作选择支持搜索、最近使用优先、自重/负重标签；动作管理可重命名并修改记录方式。
- 负重动作记录重量（kg）+ 次数；俯卧撑等自重动作只记录次数、RPE 和组类型，不要求填写重量。
- 支持正式组 / 热身组 / 递减组 / 力竭组；热身组不计入正式容量与趋势。
- 每组可记录 RPE（6–10），用于判断训练难度。
- 勾选完成一组后自动启动组间休息计时，可 ±15 秒或跳过；每个动作可独立设置休息秒数。
- 支持超级组 / Circuit：完成正式组后按编组顺序切换动作，并保留每个动作尚未保存的草稿。
- Focus Metric 会把当前正在填写的训练和上一次同动作实时比较（容量、最高重量、次数、组数、平均次数等）。
- 负重动作支持热身计算器，可按工作重量生成 2–4 组热身并直接加入当前动作。
- 负重动作支持杠铃片计算器，可选择 20 / 15 / 10 kg 杠铃杆并计算每侧常见杠铃片。
- 可把某一天的整场训练保存为模板，并按模板顺序连续训练。
- 模板支持完整管理：重命名、复制、删除、动作排序/移除，并可编辑每组类型、重量、次数和 RPE。
- 支持“一键重复上次整场训练”，不需要先建立模板。
- 支持灵活周训练计划：每天独立切换“训练 / 休息”；训练日可选择自由训练或模板并设置具体时间，休息日不显示也不保存时间；首页与训练页同步显示今日计划。
- 支持恢复顾问：每个动作可配置主要恢复部位和最多 4 个次要参与部位；主要部位按完整负荷、次要部位按约 40% 权重计入恢复估算。例如杠铃卧推同时影响胸、三头和肩前束。
- 恢复图细分肩前束 / 肩中束 / 肩后束；训练量统计仍保留原来的“肩”大类，避免历史统计口径被破坏。
- 支持恢复驱动的未来 7 天临时计划调节：保留原训练日与时间，只按恢复状态临时替换模板，可一键清除恢复基础周计划。
- 复制该动作上次训练数据。
- 保存一个动作后留在训练页，可继续记录同一天的下一个动作。
- 同一天所有动作自动组成当天训练 Session 视图。
- 动作备注。
- 训练记录支持编辑与删除。
- 首页最近训练可直接点进编辑。
- 历史页可直接编辑或删除单条动作记录。

### 进步与 PR
- 训练页为当前动作提供按真实训练日期绘制的折线，可切换最高重量、训练容量、总次数和总组数，并显示最近最多 12 个训练日的变化。
- 7 / 30 / 90 / 365 天动作趋势。
- 负重动作趋势可切换：训练容量、最高重量、总组数、总次数；自重动作只显示有意义的总组数、总次数与次数 PR。
- 全局进度页显示本周训练天数、连续活跃周、本周正式组数与本月训练天数。
- 本周 vs 上周同期、本月 vs 上月同期对比训练天数、正式组、次数和负重容量。
- 近 4 周训练分布提示会检查推/拉、股四头与后链/臀训练量差异；4 周阶段总结会归纳训练频率、总组数、重点肌群、进步动作与过难反馈。
- 月训练日历按每日正式组数显示训练强度。
- 动作可设置主肌群；进度页按主肌群统计本周正式组数并显示肌群热力图。
- 负重动作提供 1 / 3 / 5 / 8 / 10 / 12RM 历史最佳重量；自重动作显示单组/单日次数 PR。
- PR 时间线自动记录新的最高重量、次数档位 PR 或自重次数 PR。
- 展示阶段最高重量，并可查看每天具体每一组，例如 `80kg × 10`。
- 训练页显示动作历史最高重量。
- 使用 Epley 公式给出预计 1RM，用于自身长期趋势参考。
- 新纪录保存时提示 PR。
- Smart Plan：按增肌/力量/减脂目标、训练水平、每周天数、单次时长和可用器械生成周训练模板；每个训练日可独立组合胸、背、腿、后链、臀、肩部、手臂、核心等重点，并优先保留用户手动选择的训练日与时间。
- 自动模板采用“复合动作优先、孤立动作补充”的动作排序；单部位日限制同肌群动作数量，多部位日会控制每个动作的工作组数，并让 A/B 训练日轮换部分动作。
- Workout Creator：按全身/上肢/下肢/单肌群 + 可用时间快速生成一场训练，可立即开始或保存成模板。
- 训练后可反馈“太轻 / 合适 / 太难”；下一次建议会结合重量、次数、RPE 与反馈给出加重量、加次数或暂缓进阶的建议。

### 数据安全
- 数据保存在浏览器 localStorage。
- 支持导出 JSON 全量备份。
- 支持从 JSON 备份恢复。
- 当前数据 Schema 版本：15。
- 修正了旧版初始化顺序问题：已有 localStorage 数据刷新后会正确迁移，而不是异常时回退到默认状态。

## iPhone 当前访问

### 固定 HTTPS 地址（推荐）
GitHub Pages 已部署：

`https://fanyi-666.github.io/liftlog/`

该地址可在 iPhone 5G、其他 Wi-Fi 或电脑端直接访问，不要求电脑开机，也不要求与开发电脑处于同一网络。HTTPS 环境下可以正常注册 PWA Service Worker。

由于 Web 版数据保存在浏览器 localStorage，旧的局域网/临时隧道域名与这个固定域名属于不同存储空间。首次切换时，建议先在旧地址导出 JSON 备份，再在固定域名中恢复一次；之后长期使用固定域名即可。

### 临时开发隧道（备用）
项目根目录仍提供 `START_REMOTE_ACCESS.cmd`，用于本地开发时临时把 8081 暴露到公网。临时隧道地址可能变化，且依赖开发电脑持续开机，不建议作为日常使用入口。

### 同一 Wi-Fi 局域网访问（开发）
局域网测试地址仍为：

`http://192.168.0.100:8081`

电脑关机或本地服务停止后，局域网地址不可访问；固定 GitHub Pages 地址不受影响。

## App 化方向

Web V1 作为后续 iOS App 的数据与功能基线。原生 iOS 安装包最终需要 macOS + Xcode 才能完成签名、真机安装和 App Store 构建；在 Windows DevSpace 中可以继续准备 App 源码、数据模型和 Web/PWA 壳，但不能真实编译签名 iOS `.ipa`。
